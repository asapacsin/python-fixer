# Authored fixture provenance

`src/python_fixer/data/fixtures.json` contains 16 original small demonstration
functions, explicit bugs and input/output assertions authored for this repository.
`src/python_fixer/data/fixtures_v2.json` adds 37 further original functions authored
on 2026-11-23 (source `authored-fixtures-v2` = both files, 53 functions). Expected
values were written by hand and checked only by sandboxed reference runs.
These fixtures are dedicated under CC0-1.0 (public-domain dedication):
https://creativecommons.org/publicdomain/zero/1.0/legalcode . This dedication
applies only to those fixture files, not to upstream datasets or the entire repository.

No external benchmark was copied. Source and test hashes are generated by the
builder. Fixtures exercise the pipeline and are not a held-out research benchmark,
not representative of Python repair difficulty, and not evidence of model quality.
The illustrative example under examples/ retains its separate pending license
label and is never admitted into the build. Unknown external licenses are rejected.
